Adds toroidal propellers, for air and for water.

## Install

Download **propellers-0.2.0.zip** below and install it from **Preferences › Plugins › Install plugin…** (remove 0.1.0 first if replacing it is refused). It asks for no permissions. **Requires SolidCraft 0.43.0 or later.**

## New commands

| Command | Builds |
|---|---|
| Toroidal propeller | Closed loops instead of blades, for quieter drone and fan propellers |
| Toroidal marine propeller | The same, with wider loops for outboards, boats and thrusters |

Each loop leaves the hub forward and ahead in the direction of rotation, runs out to a tip bridge, and returns aft and behind. It is one loft through symmetric airfoil sections set to the propeller's pitch, turning through axial across the tip so both arms meet the air leading edge first. Inputs: loops, diameter, pitch, rotation, loop spread, axial offset between a loop's roots, root and tip chord and thickness, hub and bore. Designs whose loop roots would cross are refused with a message saying what to change.

## Unchanged

Propeller, Marine propeller, Wind turbine rotor and Ducted fan work as in 0.1.0.

## Notes

All six commands have been run by SolidCraft's own plugin runtime and kernel (headless), but not yet in the desktop app. The toroidal shape is geometric, not aerodynamically optimised; see the README.
