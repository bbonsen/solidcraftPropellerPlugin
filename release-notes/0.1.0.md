Propellers builds propellers and rotors in SolidCraft as ordinary, editable sketches, extrudes, a loft and a circular pattern. The first release.

## Install

1. Download **propellers-0.1.0.zip** below.
2. In SolidCraft (desktop): **Preferences › Plugins › Install plugin…** and pick the zip. It asks for no permissions.
3. The commands appear in the **Plugins** group on the **Model** tab and in the Plugins menu.

**Requires SolidCraft 0.43.0 or later.**

## Commands

| Command | Builds |
|---|---|
| Propeller | Drone, RC and light-aircraft propellers: constant pitch, tapered airfoil blades |
| Marine propeller | Outboard and boat propellers: Wageningen B-series outline and thickness, skew and rake |
| Wind turbine rotor | Blades shaped by Schmitz's optimum for a tip speed ratio, with a round root; or one blade alone |
| Ducted fan | EDF and cooling fans: many blades, and a duct ring as its own body |

Every command takes the blade count, diameter, hub and bore, rotation direction, airfoil thickness and camber, and a minimum trailing edge thickness for printing. The reply gives the pitch and blade angle at 0.75 R, the blade area ratio, a table of every section, and figures for each kind (pitch speed, design rpm, power estimate).

## Notes

- The plugin runs sandboxed: no file, network or settings access. Each run is one undo step.
- SolidCraft's plugin API (`craft:plugin@0.1.0`) is experimental, and so is this plugin. Every command has been run by SolidCraft's own plugin runtime and kernel (headless), but not yet in the desktop app. Please report anything that fails.
- Each blade stands on a small rectangular root pad, a few millimetres proud of the hub, so SolidCraft's kernel joins it reliably; see the README.
